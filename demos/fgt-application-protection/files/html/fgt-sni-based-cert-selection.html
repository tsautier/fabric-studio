Content Routing with SNI Based Certificate Selection

The SNI Based Certificate Selection describes a scenario where multiple DNS domains are mapped to the same virtual IP of the FortiWeb. The TCP Hello packet and Server Name Indication (SNI) are used to select the correct SSL/TLS certificate for each domain.

In this demo, we have three company websites — www.aspex.com, www.acme.com, and www.globex.com — hosted on the same web server. All three domain names resolve to the same IP address and are protected by individual SSL/TLS certificates.

  • APEX Inc. (https://www.apex.net)
